# 0002. Electron 只做管理台，不内嵌被测页面

- 日期：2026-10-19
- 状态：已废弃（被 [0006](./0006-embedded-browser-first.md) 取代）

## 背景

Electron 自带 Chromium，看起来可以直接把被测站点嵌进 `BrowserWindow` 或 `webview`，
从而省掉外部浏览器进程和 CDP。

## 决策

Electron 只渲染管理台界面。被测站点一律由外部真实浏览器进程承载，两者是独立进程。

## 被否方案

**用 Electron 的 webview / WebContentsView 承载被测页面**：

- 没有完整浏览器行为：没有地址栏、扩展、下载管理、真实 UA 与品牌特征。
- 嵌入式 WebView 的 UA 与指纹和真实浏览器不同，Google 等 OAuth 会拒绝，兼容性结论失真。
- 测试目标是「应用在真实用户浏览器里是否正常」，用自家壳测自家壳没有意义。
- Playwright 也无法接管 Electron 的内嵌页面来做自动化补充。

**Chromium 分支自研浏览器**：能完全控制，但要长期承担 Chromium 升级、安全补丁、
编解码、扩展商店、签名分发。与这个工具的定位不匹配；会话内核未来可以复用，产品形态不共享。

## 后果

- 安装包只需 Electron 运行时，不含浏览器内核。
- 管理台与被测浏览器之间只有 CDP 一条窄接口，边界清晰。
- 代价是必须自己处理进程生命周期与跨平台启动差异。
