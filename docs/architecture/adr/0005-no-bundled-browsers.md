# 0005. 不打包浏览器，启动时扫描系统引擎

- 日期：2026-10-19
- 状态：已采纳

## 背景

如果自带浏览器，安装包会大数百 MB，还要自己负责版本更新与安全补丁；但不同用户机器上
可用的浏览器差异很大。

## 决策

安装包只包含 Electron 运行时与应用代码。启动时扫描系统已安装的浏览器：

| 平台 | 探测方式 |
| --- | --- |
| Windows | `App Paths` 注册表 + Program Files / LocalAppData 标准目录 |
| macOS | `/Applications` 与 `~/Applications` 的 `.app` bundle |
| Linux | `PATH` 内的二进制、Flatpak 应用列表、Snap 目录 |

支持手动指定可执行文件，并随时重新扫描。默认优先使用系统自带的 Edge（Windows）。

## 被否方案

**打包 Chromium**：包体增加 150MB+，且必须跟随 Chromium 发布节奏升级；用户仍然会问
「为什么和我平时用的 Chrome 不一样」。

**强制要求安装 Chrome**：Windows 一定自带 Edge，要求用户额外安装是没必要的门槛。

**跟随系统默认浏览器**：默认浏览器可能是 Safari 或其他非 Chromium 引擎，无法通过
CDP 接管；而且无法传入 `--user-data-dir` 等启动参数，也无法稳定得知实际使用的 exe。

**首次运行下载 Playwright 浏览器**：这些是补丁版浏览器，行为与用户真实浏览器不同，且
下载在国内网络下不可靠。主链路不需要它。

## 后果

- 安装包体积可控，浏览器版本由厂商更新。
- 必须处理各平台的路径差异、Flatpak/Snap 沙箱、企业策略禁用远程调试。
- Firefox 只能走外部模式（多开、布局、复制密码），不做自动填充与登录态检测。
- Safari 明确不支持：没有独立 profile 目录模型，无法多账号隔离。
