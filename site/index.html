同台 Ensemble Ensemble 同台

多个身份，同一个舞台。 Multiple identities, one stage.

测权限和协作时，你总得同时开着管理员、审核员、普通用户几个窗口，反复退出登录、清 Cookie、找回密码。Ensemble 把这些窗口变成一张可以编排的台面：每个账号一个完全独立的 浏览器 Profile，一键拉起一组，边到边平铺，关掉就回收。

Testing permissions and collaboration means keeping an admin, a reviewer and a regular user signed in at once — and logging out, clearing cookies and hunting passwords in between. Ensemble turns those windows into one orchestrated stage: every account gets its own isolated browser profile, launched as a group and tiled edge to edge.

不内置浏览器，启动的是系统里的 Chrome / Edge / Brave / Vivaldi / Firefox； 不放云端、不需要登录。

No bundled browser: it drives Chrome / Edge / Brave / Vivaldi / Firefox already installed on your machine. Nothing leaves the computer, no account required.

Model

三层模型，一个作用域一条隔离线

Three layers, one isolation boundary

环境是被测目标，身份是账号，场景是一次编排。换环境不会串登录态，换身份不会带出别人的 Cookie。

An environment is the target, an identity is an account, a scene is one run. Switching environments never mixes sessions; switching identities never leaks someone else's cookies.

01

环境

Environment

作用域 · 不隔离

Scope · not isolated

站点地址、登录入口、登录检测地址与默认凭据。左侧导航第一项，切换环境同时切换身份与场景。

Base URL, login path, session-check endpoint and default credentials. It is the first item in the rail; switching it switches the identities and scenes you see.

02

身份

Identity

账号 · 完全隔离

Account · fully isolated

一个账号加一个独立的浏览器 Profile。登录态、Cookie、扩展、下载行为互不影响，和真人操作一致。

One account plus one dedicated browser profile. Sessions, cookies, extensions and download behaviour stay separate — exactly like a person driving that browser.

03

场景

Scene

编排 · 不隔离

Orchestration · not isolated

一次要同时拉起的身份组合与窗口布局。把成员拖到槽位即可指定位置，换位后正在运行的窗口跟着移动。

The set of identities to launch together and how they tile. Drag a member onto a slot to place it; open windows follow when you reassign.

Capabilities

为「同时用几个账号」这件事做的细节

Details that matter when several accounts are open

启动即填

Fill on launch

窗口打开后自动填入账号密码；租户名、公司码等字段按标签匹配，环境级下发、身份级覆盖。

Credentials are typed in as the window opens. Tenant or company codes are matched by label, set per environment and overridable per identity.

真实隔离

Real isolation

每个身份独立 Profile，不复用你日常浏览器的目录；多开不串登录态。

Each identity gets its own profile directory — never your daily browser's — so parallel windows never share a session.

场景编排

Scene orchestration

一键拉起一组身份，按布局边到边平铺，不留无用外边距；启动失败会回收本次已开的窗口。

Launch a group at once, tiled edge to edge with no wasted margin. A failed launch still reclaims the windows it already opened.

布局可自定义

Custom layouts

内置无布局 / 1×1 / 2×1 / 1×2 / 2×2 / 3×1，也可以拖方块画自己的布局并保存成预设， 拖动时自动吸附并显示参考线。

Built-in no-layout / 1×1 / 2×1 / 1×2 / 2×2 / 3×1, plus a drag-and-drop editor for saved presets, with snapping and alignment guides.

误关可单开

Reopen one member

关掉某个账号的窗口不必重启整幕，在场景详情里单独重开即可，位置也保持原槽位。

Closed one account by mistake? Reopen just that window from the scene detail; it returns to its assigned slot.

凭据保护

Credential protection

默认走系统密钥环（DPAPI / Keychain / keyring），可再加一层应用主密码；密码只写不读， 不进渲染进程、不进日志。

OS keychain by default (DPAPI / Keychain / keyring), optionally hardened with a master password. Passwords are write-only: never returned to the UI, never logged.

干净会话

Clean sessions

不登录、关闭即自动删除的临时窗口；也能开一个不属于任何环境的空白会话，单独验证一条链接。

A throwaway window that never logs in and is deleted on close — including a blank one that belongs to no environment, for checking a single link.

AI 直接录入

AI does the data entry

内置 MCP 端点。账号在容器或数据库里建好后，AI 可以直接写入环境、身份与场景，不必手填。

A built-in MCP endpoint. Once accounts exist in your container or database, an AI client registers the environments, identities and scenes for you.

托盘常驻

Tray mode

关窗只是隐藏，浏览器与 AI 端点继续运行；彻底退出会先停 MCP、再按 Profile 路径回收自己开的浏览器。

Closing the window only hides it; browsers and the AI endpoint keep running. A real quit stops MCP first, then reclaims only the browsers it launched.

Interface

界面

Interface

左侧管环境 / 身份 / 场景 / 设置，顶栏只做环境切换，运行中的窗口在右侧一览。

The rail manages environments, identities, scenes and settings; the title bar only switches environments, and running windows are listed on the right.

MCP

让 AI 建好账号，Ensemble 只负责录入

Let the AI create accounts; Ensemble records them

在你本机的回环地址上开一个 MCP 端点，AI 客户端可以列出、创建和修改环境、身份、场景与布局， 也可以启动窗口、检测登录态。端点只绑 127.0.0.1，必须带 Bearer Token，并校验 Host 与 Origin。

Ensemble serves an MCP endpoint on the loopback interface. An AI client can list, create and edit environments, identities, scenes and layouts, and also launch windows and check sessions. The endpoint binds 127.0.0.1 only, requires a bearer token, and validates Host and Origin.

  • 四档权限：读 / 写 / 运行 / 删除，后三档由设置页开关控制。
  • Four permission tiers: read / write / run / delete — the last three are toggles in settings.
  • 删除类工具必须显式传 confirm: true。
  • Delete tools require an explicit confirm: true.
  • 没有读密码的工具：密码只进加密凭据库，永远不回显。
  • No tool reads a password back; credentials only go into the encrypted vault.
  • 每次调用写一行审计日志，密码、口令与 Token 递归脱敏。
  • Every call appends an audit line, with passwords, passphrases and tokens redacted.

发布产物没有代码签名。个人开源项目不购买证书，首次运行时系统会提示来源不可信， 属于预期行为。Windows 在 SmartScreen 里点「更多信息 → 仍要运行」；macOS 右键应用选择「打开」， 或执行 xattr -dr com.apple.quarantine /Applications/Ensemble.app。

Release builds are not code-signed. A personal open-source project does not buy certificates, so a "source not verified" warning on first launch is expected. On Windows choose More info → Run anyway; on macOS right-click the app and choose Open, or run xattr -dr com.apple.quarantine /Applications/Ensemble.app.

设置 →「关于」可以对比 GitHub 上的最新版本；更新方式是用新安装包覆盖安装，不会自动下载。

Settings → About compares your version with the latest release on GitHub. Updates are installed by running the newer installer; nothing is downloaded automatically.
